福間陸翔の学生ポートフォリオ。2026年9月17日付の要件定義書と提供されたFigmaを基に、ユーザーの変更指定を反映しています。

## 開き方と構成

index.htmlをブラウザで開きます。外部フォント・SNS・動画・地図にはインターネット接続が必要です。外部埋め込みの確認にはHTTPで配信した環境を使用してください。

- index.html：サイト紹介とプロフィール。
- hobby.html：提供された画像10枚の趣味ギャラリー。
- contact.html：Instagram・X・YouTubeと羽田空港の紹介・地図。
- style.css：共通デザイン、スマホ・タブレット用表示。
- scripts/menu.js：メニュー開閉、Escape、画面幅変更時のフォーカス制御。
- images/：使用画像。プロフィール・趣味の元ファイルは「プロフィール　趣味」にも保持。
- tests/verify.mjs：構造、画像参照、メニュー動作の自動確認。

提出用のサイト本体は上記HTML・CSS・scripts・imagesとこのREADMEです。style 1.cssは使用していません。

## 使用技術とデザイン

HTML5・CSS3・標準JavaScriptを使用。レイアウト用フレームワークは使用していません。Playfair Display、Poppins、Noto Serif JPをGoogle Fontsから読み込みます。

サイトの配色は指定パレットを使用。写真の色は加工していません。本文16px、PC見出し72px・40px、最大幅1200px、通常のトランジション0.3秒を基本とします。小さなラベルは読みやすさを優先して指定パレットの濃い文字色を使用します。

768px以下はプロフィール・SNS・Accessを縦並びにします。趣味は768px以下で2列、769〜1023pxで3列、1024px以上で5列×2行です。スマホの趣味説明は14pxに修正しました。

## SNSの実装

Instagramのプロフィール埋め込み設定、Xの公式タイムライン、YouTubeのiframeを配置しています。埋め込み外にも通常リンクを残しています。Instagram・Xの読み込みはアカウントの埋め込み許可やサービス側の制限に左右されます。Instagramのプロフィール埋め込みが利用できない場合は、対象投稿のURLまたは公式の埋め込みコードに差し替える必要があります。

要件書のSNSプラグインを実装するため、Instagramのembed.jsとXのwidgets.jsを使用しています。「外部ライブラリはGoogle Fontsのみ」という一般指定に対して、SNS公式スクリプトをプラグイン要件の対象として扱っています。汎用の外部JavaScriptライブラリは追加していません。

参考：[X公式の埋め込み手順](https://help.x.com/en/using-x/embed-x-feed)、[YouTube公式の埋め込み仕様](https://developers.google.com/youtube/player_parameters)。
